# Mohamed Nabil S - Personal Developer Portfolio

A modern, startup-level personal portfolio website designed for Mohamed Nabil S, a Frontend Developer and AI/Data Science Graduate. 

This project features a premium "dark luxury" UI with glassmorphism elements, gold accents, and smooth animations, built specifically to attract recruiters and showcase professional projects.

## 🚀 Features

- **Modern Dark Luxury UI**: Deep navy/black background with premium gold accent highlights.
- **Glassmorphism Design**: Semi-transparent frosted glass cards and elements (`backdrop-filter`).
- **Fully Responsive**: Mobile-first design that looks great on desktops, tablets, and smartphones.
- **Smooth Animations**: Integrated scroll reveal animations using the `IntersectionObserver` API.
- **Semantic HTML5**: Clean, accessible, and SEO-friendly markup.
- **Pure CSS3 & Vanilla JavaScript**: No heavy frameworks like Bootstrap, ensuring optimal performance and load times.
- **Interactive Elements**: 
  - Sticky navigation bar
  - Mobile hamburger menu
  - Floating WhatsApp chat button
  - Scroll-to-top functionality
  - Dynamic scroll progress bar
  - Form submission state handling

## ⚙️ Getting Started

To view the website locally, simply clone the repository and open the `index.html` file in any modern web browser. 

No build tools or local servers are strictly required, though a tool like VS Code's "Live Server" extension is recommended for the best development experience.

```bash
git clone <repository-url>
cd mohamed-nabil-portfolio
# Open index.html in your browser
```

## 📝 Configuration Needed Before Deployment

Before deploying this portfolio, ensure you complete the following:

1. **Profile Image**: Replace `images/profile/placeholder.jpg` with a professional photo of yourself.
2. **Project Images**: Add screenshots of your projects to `images/projects/` and update the paths in `index.html`.
3. **Resume**: Replace `resume/Mohamed_Nabil_Resume.pdf` with your actual updated resume.
4. **Links Check**: Verify all GitHub, LinkedIn, and Live Demo links point to the correct URLs.
